# Auto Poster — Автоматическая расклейка рекламы

Автоматический расклейщик с генерацией текстов через Groq (LLaMA 3.3 70B).

## Настройка

1. Получить API-ключ на [console.groq.com](https://console.groq.com)
2. Добавить ключ в GitHub Secrets (`GROQ_API_KEY`)
3. Настроить Telegram (опционально)
4. Запустить вручную через Actions или по расписанию

## Запуск

- Автоматически: каждые 6 часов
- Вручную: Actions → "Auto-расклейка" → "Run workflow"

## Бюджет

- **Groq API:** Бесплатно (14 400 запросов/день)
- **Хостинг:** Бесплатно (GitHub Actions)
- **Итого:** $0
